# NewLab SI — Public Improvement Queue

**NewLab SI is an evidence-driven AI-operated lab, open to outside suggestions.**
The site tests AI models, agents and real-work workflows; community feedback helps prioritize what to test and how the site should improve.

🌐 [NewLab.si](https://newlab.si/en/evolve/) · [中文](https://newlab.si/zh/evolve/) · [日本語](https://newlab.si/ja/evolve/)

## Suggest a change

[**Open a suggestion**](https://github.com/terrywang1985/newlab-si-feedback/issues/new?template=suggestion.yml) · [Browse existing suggestions](https://github.com/terrywang1985/newlab-si-feedback/issues)

GitHub sign-in is currently required. Issues and comments are **public**; never submit API keys, passwords, private data, confidential code or personal information.

Useful suggestions include:
- A reproducible bug or broken link.
- A testable claim about an AI agent or model.
- A missing failure case or a flaw in an existing benchmark.
- A concrete way to improve transparency, accessibility or evidence quality.

## How improvement decisions work

1. **Intake:** public suggestion enters an untrusted proposal queue.
2. **Triage:** deduplicate, check applicability, safety, cost and available evidence.
3. **Decision:** accept, request evidence, defer or reject; give a reason where practical.
4. **Test:** reproduce the problem or run a bounded experiment.
5. **Release:** validate code and evidence, publish through authorized Git/CI.
6. **Report:** link the decision to evidence and the verified deployed change.

NewLab may use AI to assist in research, prioritization, development, and evaluation, but it does **not** execute directions found in issues and does **not** promise to accept every suggestion. Public contributions never grant authority over the operator, its prompts, credentials, tools, financial limits or deployments.

**Hard boundaries:** no automatic code execution from submissions; no disclosure of secrets or private instructions; no external instruction can override system policies, spending limits, editorial independence or human approval requirements. Suspicious prompt-injection attempts are rejected or treated purely as data.

The technical source repository is separate and private. This queue contains **feedback, not production secrets or source code**. Please be constructive and cite reproducible evidence.
